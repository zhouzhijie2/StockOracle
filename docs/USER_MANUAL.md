## 1. 安装与启动

### Windows 用户

下载打包好的 `StockOracle.exe`，**双击即可运行**，无需安装 Python。

### macOS 用户

下载 `.dmg` 文件，拖入应用文件夹即可。

### 开发者模式（源码运行）

```bash
git clone https://github.com/zhouzhijie2/StockOracle.git
cd StockOracle
pip install -r requirements.txt
python run.py
```

## 2. 首次使用指南

首次启动后，请按照以下步骤操作：

```
1. 打开「数据中心」
    ↓
2. 点击「更新股票列表」（获取约 5500 只 A 股）
    ↓
3. 点击「增量更新日线」（下载历史 K 线数据）
    ↓
4. 打开「选股中心」运行选股
    ↓
5. 打开「盯盘中心」添加自选股开始盯盘
```

## 3. 数据中心

### 功能说明

| 按钮 | 功能 |
|---|---|
| **更新股票列表** | 从数据源拉取最新的 A 股股票列表（代码、名称、行业） |
| **增量更新日线** | 智能检测本地数据，仅下载缺失的交易日数据（推荐） |
| **全量更新日线** | 强制重新下载所有数据（首次或数据损坏时使用） |
| **数据源选择** | 切换 AkShare / efinance（默认 AkShare） |

### 注意事项

- 首次全量更新约需 15-30 分钟（受网络速度影响）
- 每日增量更新仅需 1-2 分钟
- 数据会自动缓存到本地 SQLite 数据库，离线可用

## 4. 选股中心

### 预置规则

| 规则名称 | 说明 | 参数 |
|---|---|---|
| **consolidation_breakout** | 底部横盘缩量 + 今日放量上涨（核心策略） | 横盘天数、振幅、量比阈值 |
| **ma_cross** | MA5 上穿 MA20 | 短/长均线周期 |
| **macd_golden** | MACD 日线金叉 | 无 |
| **new_high_breakout** | 放量突破 N 日新高 | N 天、量比阈值 |
| **limit_up** | 涨停板检测 | 自动识别市场类型 |

### 核心策略（consolidation_breakout）参数说明

| 参数 | 默认值 | 说明 |
|---|---|---|
| consolidation_days | 20 | 横盘窗口（交易日） |
| consolidation_range_pct | 15 | 横盘期间最高/最低价比 ≤ 1.15 |
| shrink_vol_ratio | 0.7 | 横盘后期量 / 前期量 ≤ 0.7 |
| today_min_pct | 5.0 | 今日涨幅下限（%） |
| today_max_pct | 11.0 | 今日涨幅上限（%） |
| vol_expansion_ratio | 2.0 | 今日成交量 / 20 日均量 ≥ 2.0 |
| price_above_ma20 | True | 收盘价 > MA20 |

### 操作步骤

1. 在左侧选择选股规则
2. 调整参数（可选）
3. 设置返回数量（Top N）
4. 点击 **▶ 运行选股**
5. 双击结果行可跳转行情中心查看详情
6. 点击「导出 CSV」保存结果

## 5. 盯盘中心

### 自选股分组

- 支持多个分组（默认、短线、中长线等）
- 点击 `+` 新建分组，`-` 删除分组
- 在输入框输入 6 位代码后回车添加股票

### 盯盘控制

| 设置 | 说明 |
|---|---|
| 刷新间隔 | 默认 5 秒，可调整 1-600 秒 |
| 开始/停止 | 控制盯盘开关 |

### 触发条件

勾选需要监控的条件：
- ✅ 涨幅 ≥ 3%
- ✅ 跌幅 ≥ 3%
- ✅ 量比 ≥ 2
- ✅ 换手率 ≥ 5%

### 触发提醒

满足条件时：
1. 系统通知弹窗
2. 触发日志记录
3. 可选提示音（在设置中开启）

## 6. 行情中心

### 功能

- **搜索股票**：输入 6 位代码查询
- **实时行情**：现价、涨跌幅、今开/最高/最低、成交量、量比
- **K 线图**：显示最近 120 天日线，叠加 MA5/MA10/MA20
- **历史数据**：表格展示最近历史 K 线

## 8. 常见问题

### Q1：为什么数据更新很慢？

A：首次全量更新需要下载约 5500 只股票的历史数据，建议在非交易时间进行。增量更新通常很快。

### Q2：盯盘时收不到通知？

A：请检查系统通知权限：
- Windows：设置 → 系统 → 通知
- macOS：系统设置 → 通知 → 找到 StockOracle

### Q3：可以离线使用吗？

A：**可以**。盘后选股完全离线可用；实时行情需要联网。

### Q4：数据会上传到服务器吗？

A：**不会**。所有数据存储在本地 SQLite 数据库，不上传任何信息。

### Q5：如何备份数据？

A：数据文件位于：
- Windows：`%APPDATA%\StockOracle\oracle.db`
- macOS：`~/Library/Application Support/StockOracle/oracle.db`
