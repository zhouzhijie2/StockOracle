## 1. 项目定位

**StockOracle** 是一款面向 A 股个人投资者的跨平台桌面应用（Windows / macOS），提供以下核心能力：

| 能力 | 说明 |
| --- | --- |
| 规则选股（离线） | 基于日线 / 周线 / 分钟线，按用户可配置的规则从全市场 5500+ 只股票中筛选候选标的 |
| 规则盯盘（实时） | 盘内按秒级刷新，监视自选股或全市场，触发条件时弹出提醒 / 声音提示 |
| 自选股管理 | 添加 / 分组 / 排序 / 导入导出自选股列表 |
| 行情快照 | 个股当日涨跌、关键均线、量能、资金流向等一屏展示 |
| 规则引擎（可视化配置） | 预置 + 自定义规则组合（横盘缩量、放量突破、均线金叉、MACD、涨停板等） |

产品关键词：**离线可跑、零成本数据、跨平台、轻量 GUI、规则即策略**。

## 2. 目标用户与场景

### 2.1 用户画像

- **散户 / 上班族股民**：白天没时间盯盘，需要收盘后用工具复盘选股，第二天再观察。
- **技术型投资者**：熟悉均线、量能、MACD、涨停板等经典技术形态，希望把"手工翻股票"自动化。
- **小型量化团队（1-2 人）**：希望快速验证策略因子，但不想投入大型回测系统。

### 2.2 典型场景

1. **盘后选股**：每个交易日 15:30 后，使用"底部横盘缩量 + 今日放量上涨 5%-7%"规则跑一遍全市场，输出 10-30 只候选。
2. **盘中盯盘**：开盘后，把昨日选出的股票加入自选池，设置"价格突破前高 + 量比 > 2"提醒，触发时弹框提示。
3. **长期跟踪**：每周日对自己的策略池跑一遍"周线 MACD 金叉"，作为下周观察清单。
4. **自定义策略**：通过组合规则字段（如：流通市值 < 200 亿 + 价格 < MA20 + 今日涨幅 > 3%）快速筛选。

## 4. 核心选股规则设计

本节把用户需求中"底部横盘缩量 + 突然放量 5%-7%"规则做**正式量化定义**。

### 4.1 规则 R1：底部横盘 + 缩量 + 今日放量上涨

**适用周期**：日线  
**参数**（均在 GUI 可编辑，保存为 JSON）：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `consolidation_days` | 20 | 横盘窗口（交易日） |
| `consolidation_range_pct` | 15 | 横盘期间最高价 / 最低价 ≤ 1.15（即振幅 ≤ 15%） |
| `shrink_vol_ratio` | 0.7 | 横盘后期（最近 5 日）平均成交量 / 前 15 日平均成交量 ≤ 0.7 |
| `today_min_pct` | 5.0 | 当日涨幅下限（%） |
| `today_max_pct` | 7.0 | 当日涨幅上限（%） |
| `vol_expansion_ratio` | 2.0 | 当日成交量 / 最近 20 日均量 ≥ 2.0 |
| `price_above_ma20` | true | 今日收盘价 > MA20（排除伪突破） |

**评分（用于排序）**：  
`score = 涨幅偏离度(%) + 量能放大倍数 * 2 + (1 - 横盘振幅/15%) * 3`

**排除条件**：
- ST / *ST / 退市整理 → 排除
- 停牌 / 今日涨跌停一字板 → 排除
- 流通市值 > 1000 亿（可调节）→ 可选排除
- 新股上市未满 60 日 → 可选排除

## 5. 非功能需求

| 类别 | 要求 |
| --- | --- |
| **跨平台** | Windows 10/11（x64）、macOS 12+（Intel + Apple Silicon），同一份源码，分别用 PyInstaller 打包 |
| **性能** | 全市场日线选股运行 ≤ 60 秒（首次下载除外）；盘中刷新延迟 ≤ 5s |
| **离线能力** | 盘后选股完全离线可用；实时行情需联网 |
| **数据准确性** | K 线与东方财富 / 同花顺公开数据误差 ≤ 0.01 元 |
| **安装包体积** | ≤ 150 MB（UPX 压缩后） |
| **启动时间** | ≤ 5 秒 |
| **安全** | 不收集用户数据；不上传自选股列表到任何服务器 |
| **合规** | 不涉及自动交易、不提供买卖建议，仅做数据筛选和技术指标展示 |

## 8. 验收标准（DoD）

1. 在 Windows 11 与 macOS 14 各一台机器上，安装并启动 ≤ 5s，无白屏 / 无崩溃。
2. 盘后全市场选股（R1）运行：
   - 首次从 0 拉取日线数据（5500 只，每只 500 日），总耗时 ≤ 30 分钟（限速情况下）
   - 之后每日增量更新 ≤ 2 分钟
   - 筛选运行 ≤ 60 秒，输出候选 5-50 只
3. 盘中盯盘：自选 100 只，5 秒刷新，连续运行 4 小时无内存泄漏（RSS 增长 ≤ 50MB）。
4. 触发提醒：当某只股票触发规则时，系统通知弹框可点击跳转详情页。
5. 可导出 / 导入自选股与规则方案 JSON，跨平台一致。

## 10. 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 数据源接口变更 | 高 | (1) 多层数据源抽象（DataProvider 接口）(2) 自动回退到备用数据源 (3) 监控告警 |
| 免费接口被限流 | 中 | 限速 + 本地缓存；首次全量拉取建议深夜执行 |
| PyInstaller 打包体积大 | 中 | UPX + 按需裁剪依赖；排除 pandas/numpy 未使用模块 |
| 跨平台 GUI 差异 | 低 | 使用 PySide6 + QSS 统一样式 |
| 全市场筛选耗时过长 | 中 | pandas/numpy 向量化计算；多进程分批；结果按评分取 Top-N |
